# Целевая аудитория

1. Основная - потребители, которые сознательно подходят к выбору продуктов питания и нуждаются в удобном инструменте для оценки их полезности.
2. Возможная - производители, которые создают продукт из качественных веществ. Например, не используют пальмовое масло. 

## Основные сегменты целевой аудитории
### 1. "Осознанные родители" (самая широкая группа)
   * Демография: 25-45 лет, семьи с детьми
   * Мотивация: Забота о здоровье детей, контроль за питанием
   * Боли: Нехватка времени на изучение составов, недоверие к маркетингу
   * Пример запроса: "Безопасен ли этот йогурт для ребенка 3 лет?"

### 2. "ЗОЖ-энтузиасты"
   * Демография: 18-40 лет, активные, следящие за трендами
   * Мотивация: Оптимизация питания для спорта/здоровья
   * Боли: Сложность разбора состава, зеленый камуфляж (greenwashing)
   * Пример: "Где меньше скрытых сахаров в этих протеиновых батончиках?"

### 3. "Люди с ограничениями по здоровью"
   * Демография: Разный возраст, с медицинскими показаниями
   * Мотивация: Избегание аллергенов, контроль хронических заболеваний
   * Боли: Риск покупки неподходящих продуктов
   * Пример: "Есть ли в этом соусе скрытые аллергены?"

### 4. "Начинающие в теме здорового питания"
   * Демография: 16-30 лет, только начинают разбираться
   * Мотивация: Желание улучшить питание, но нет экспертизы
   * Боли: Перегруженность информацией, сложность терминов
   * Пример: "Чем опасно пальмовое масло и где оно скрывается?"

### 5. "Рекламные отделы, производителей продукта" (возможная аудитория)

## Ключевые характеристики аудитории
### Психографика:
   * Высокая осознанность в покупках
   * Доверие к технологиям и данным
   * Активные пользователи смартфонов
   * Читают отзывы и исследования

### Поведенческие паттерны:
   * Сканируют QR-коды в магазинах
   * Ищут альтернативы привычным продуктам
   * Готовы платить за премиум-качество
