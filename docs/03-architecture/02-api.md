#### 2. Бизнес-функции (методы)

**2.1 Управление сканированиями**
1. **`scan.create`** - Создание нового сканирования
    - *Бизнес-правило*: Авторизованные пользователи могут создавать до 100 сканирований в день
    - *Валидация*: Для типа "manual" - минимум 10 символов в dataText

2. **`scan.get`** - Получение результата сканирования по ID
    - *Бизнес-правило*: Доступ только для владельца сканирования
    - *Валидация*: Данные сканирования, связанный состав и анализ

3. **`scan.history`** - История сканирований пользователя
    - *Бизнес-правило*: Возвращает последние 50 сканирований с пагинацией
    - *Фильтры*: По типу, дате, рейтингу анализа
 
**2.2 Управление составами**   
1. **`composition.get`** - Получение состава по ID
    - *Бизнес-логика*: Увеличивает useCount при каждом запросе

2. **`composition.find-similar`** - Поиск похожих составов
    - *Критерии совместимости*:  
      - Схожесть текста состава ≥ 70%
      - Та же категория продуктов
      - Учет рейтинга безопасности
 
**2.3 Анализ состава**
1. **`analysis.get`** - Получение анализа состава
    - *Бизнес-логика*: Интеграция с AI-моделью Llama 3 для анализа
    - *Кэширование*: Повторные запросы возвращаются из кэша

2. **`analysis.regenerate`** - Перегенерация анализа
    - *Бизнес-правило*: Доступно только владельцу сканирования
    - *Лимит*: Максимум 3 перегенерации в сутки

**2.4 Управление компонентами**
1. **`components.search`** - Поиск компонентов
    - *Фильтры*:По названию, уровню риска, научному имени
    - *Сортировка*: По популярности, уровню риска

2. **`components.get-details`** - Получение детальной информации о компоненте
    - *Фильтры*:По названию, уровню риска, научному имени
    - *Включает*: Описание, источники, связанные риски для здоровья

**2.4 Хранение фото**
1. **`uploader.download`** - Скачивание фото
   - *Бизнес-правило*: Доступно только co scan ID

2. **`uploader.upload`** - Сохранение фото
   - *Бизнес-правило*: Фото может быть загружена при создании Scan

#### 3. Бизнес-правила
**3.1 *Бесплатные пользователи* - 100 сканирований/день**

**3.2 *Премиум пользователи* - 1000 сканирований/день**

**3.3 *Максимальный размер фото* - 10MB**

**3.4 Валидация состава**
1. **Минимум 10 символов для ручного ввода**
2. **Максимум 5000 символов для текста состава**
3. **Поддержка кириллицы, латиницы и специальных символов (E-коды)**

**3.5 Рейтинговая система**
- **`dark_red` (крайне опасно):** Рейтинг 1.0-1.5, критические проблемы здоровья
- **`red` (очень опасно):** Рейтинг 1.5-2.0, серьезные риски для здоровья
- **`orange` (опасно):** Рейтинг 2.0-2.5, выраженные негативные эффекты
- **`yellow` (предупреждение):** Рейтинг 2.5-3.0, умеренные проблемы
- **`light_yellow` (незначительный риск):** Рейтинг 3.0-3.5, минимальные негативные эффекты
- **`light_green` (относительно безопасно):** Рейтинг 3.5-4.0, незначительные риски
- **`green` (безопасно):** Рейтинг 4.0-4.5, хороший состав
- **`dark_green` (идеально):** Рейтинг 4.5-5.0, оптимальный состав

**3.6 Кэширование анализов**
1. **Анализы кэшируются на 30 дней**
2. **При изменении базы знаний компонентов** - перегенерация по запросу

#### 4. Бизнес-метрики успеха

**4.1 Скорость обработки**
1. **95% сканирований обрабатываются < 3 секунд (PERF-002)**
2. **OCR обработка фото < 1.5 секунд (PERF-003)**

**4.2 Точность анализа**
1. **Точность определения опасных компонентов ≥ 90% (FR-014)**
2. **Точность распознавания текста ≥ 95% (NFR-007)**

**4.3 Надежность системы**
1. **Доступность 99.5% (NFR-006 для оффлайн работы)**
2. **Обработка 1000+ одновременных запросов (SCAL-012)**

**4.4 Ограничения API**
1. **Бесплатные пользователи: 100 запросов/день**
2. **Премиум пользователи: 1000 запросов/день**
