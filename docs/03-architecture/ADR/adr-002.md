## 🖼️ ADR-002: Архитектура обработки фото состава продуктов
**Статус**: Принято  
**Дата**: 2025-11-10  
**Участники**: Mobile Lead, Backend Architect, Computer Vision Engineer

#### 1. Контекст и проблема
> "Как обеспечить распознавание текста состава с фото с точностью $\geq 95\%$ (NFR-007) при различных условиях освещения и качестве фото, сохраняя при этом оффлайн-работу (NFR-006)?"

#### 2. Архитектурно значимые требования (ASR)
| ID требования | Текст требования | Тип | Источник |
|---------------|------------------|-----|----------|
| NFR-007 | Точность распознавания текста $\geq 95\%$ | НФТ | Требование п.7.1 |
| PERF-003 | Время обработки фото $\leq 5$ сек | НФТ | Требование п.1.1 |
| NFR-006 | Работа без интернет-соединения | НФТ | Требование п.6.2 |
| FR-015 | Поддержка ручного исправления распознанного текста | ФТ | User Story US-002 |

#### 3. Анализ альтернатив
| Требование \ Решение | Google Vision API | **PaddleOCR (Локально)** | Tesseract 5.3 (с предобработкой) |
|----------------------|-------------------|--------------------------|---------------------------------|
| **NFR-007 (Точность)** | ✅ ~98% | **✅ ~97% (высокая точность)** | ✅ ~96% |
| **PERF-003 (Скорость)** | ✅ ~2.1 сек | **✅ ~1.5 сек (быстрое решение)** | ⚠️ ~3.8 сек |
| **NFR-006 (Оффлайн)** | ❌ Требует API | **✅ Локальная** | ✅ Локальная |
| **Стоимость** | $\sim \$ 1.5$/1000 запросов | **✅ Бесплатно** | ✅ Бесплатно |
| **Поддержка кириллицы** | ✅ | **✅ Отличная** | ✅ Хорошая |

#### 4. Выбранное решение
**PaddleOCR (PP-OCRv4) + OpenCV preprocessing**:
- **Предобработка изображения**: Использование **OpenCV** для нормализации, улучшения контраста и коррекции перспективы.
- **Движок OCR**: **PaddleOCR** с моделью, оптимизированной для сложных условий освещения и разнообразных шрифтов.
- **Пост-обработка**: Валидация текста с помощью регулярных выражений и словаря пищевых ингредиентов.

#### 5. Обоснование
- **NFR-006 & COST-001**: Выбор **PaddleOCR** обеспечивает полную локальную работу и отсутствие операционных затрат.
- **NFR-007 & PERF-003**: **PaddleOCR** превосходит Tesseract по скорости и точности, особенно на кириллице и в реальных условиях (фотографии упаковок), что позволяет легко уложиться в требования.

#### 6. Последствия
- ✅ **Позитивные**:
  - Высокая точность, сравнимая с коммерческими API, при сохранении оффлайн-работы.
  - Высокая скорость обработки (PERF-003).
- ⚠️ **Негативные**:
  - Требует установки зависимостей (PyTorch/ONNX) на сервер или мобильное устройство.
  - Для лучшей точности может потребоваться модель большего размера.
- 🔧 **Зависимости**:
  - ADR-001: Распознанный текст передается в AI-модель для анализа.
