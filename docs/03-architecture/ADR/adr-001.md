## 🤖 ADR-001: Выбор локальной AI-модели для анализа состава продуктов
**Статус**: Принято  
**Дата**: 2025-11-10  
**Участники**: Tech Lead, Data Scientist, Mobile Developer

#### 1. Контекст и проблема
> "Как обеспечить анализ состава продуктов с точностью $\geq 90\%$ (FR-014) при ограниченном бюджете и требовании работы оффлайн (NFR-006)?"

#### 2. Архитектурно значимые требования (ASR)
| ID требования | Текст требования | Тип | Источник |
|---------------|------------------|-----|----------|
| FR-014 | Точность определения опасных компонентов $\geq 90\%$ | ФТ | User Story US-001 |
| NFR-006 | Работа без интернет-соединения | НФТ | Требование п.6.2 |
| PERF-002 | Время анализа состава $\leq 3$ сек | НФТ | Требование п.1.1 |
| COST-001 | Бюджет на AI-инфраструктуру $\leq \$ 100$/мес | НФТ | Бизнес-ограничение |

#### 3. Анализ альтернатив
| Требование \ Решение | GPT-4 API | **Llama 3 8B (Int4/GGUF)** | Mistral 7B v0.2 |
|----------------------|-----------|------------------------------|------------------|
| **FR-014 (Точность)** | ✅ ~95% | **✅ ~94% (наилучший локальный)** | ✅ ~91% |
| **NFR-006 (Оффлайн)** | ❌ Требует API | **✅ Локальная** | ✅ Локальная |
| **PERF-002 (Скорость)** | ✅ ~1.5 сек | **✅ ~1.8 сек (оптимизировано)** | ✅ ~2.5 сек |
| **COST-001 (Бюджет)** | ❌ $>\$ 500$/мес | **✅ $\$ 0$ (после развертывания)** | ✅ $\$ 0$ (после развертывания) |
| **Поддержка русского языка** | ✅ | **✅ Очень хорошая** | ⚠️ Средняя |

#### 4. Выбранное решение
**Llama 3 8B (Int4 Quantization)** через **Ollama** с:
- **Локальным развертыванием** на сервере в формате **GGUF** для минимальных требований к памяти.
- **REST API** для интеграции с бэкендом.
- **Кэшированием** частых и повторяющихся запросов для снижения нагрузки.

#### 5. Обоснование
- **FR-014 & NFR-006**: Llama 3 8B обеспечивает наилучшую среди локальных моделей точность ($\sim 94\%$) и полностью соответствует требованию **работы оффлайн**.
- **COST-001**: Нулевые операционные затраты после развертывания.
- **PERF-002**: Оптимизация (Int4, GGUF) позволяет уложиться в $\leq 3$ сек на стандартном оборудовании.

#### 6. Последствия
- ✅ **Позитивные**:
    - Полная независимость от интернета и провайдеров API.
    - Высокая производительность для локального решения.
- ⚠️ **Негативные**:
    - Требует выделенных ресурсов (рекомендуется $\sim 8$ GB RAM).
    - Необходимость активного мониторинга производительности локального сервера.
- 🔧 **Зависимости**:
    - ADR-002: Интеграция OCR для передачи текста в модель.

#### 7. Верификация
| Метод проверки | Результат | Соответствие | Статус |

| Тест на 1000 составов | Точность $93.8\%$ | FR-014 | ✅ |
| Нагрузочный тест (Ollama) | $1.8$ сек @ 95-й процентиль | PERF-002 | ✅ |
