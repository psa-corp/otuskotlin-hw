### Карточка тестового случая

**Название:** Обработка запроса несуществующего анализа (Негативный тест)

**Описание:**
Проверка корректности обработки ошибок API при запросе анализа, которого нет в системе. Метод `POST /analysis/get`.

**Предусловия:**
1. ID `analysis_99999` гарантированно отсутствует в базе данных.

**Шаги:**
1. Сформировать HTTP POST запрос на эндпоинт `/v1/analysis/get`.
2. В теле запроса передать JSON c `analysisId`: "analysis_99999".
3. Отправить запрос.
4. Проверить HTTP статус-код ответа.
5. Проверить структуру ошибки в теле ответа (согласно схеме `ErrorResponse`).

**Ожидаемый результат:**
1. Статус ответа: **404 Not Found**.
2. Тело ответа содержит JSON с описанием ошибки (поле `message` не пустое).

**Тип теста:** API тест (Negative)
**Связанный метод:** `/analysis/get`
