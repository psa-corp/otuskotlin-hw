### Карточка тестового случая

**Название:** Загрузка фотографии состава для распознавания

**Описание:**
Проверка метода `POST /composition/create/photos`, который принимает бинарные файлы (фото) и метаданные через `multipart/form-data`.

**Предусловия:**
1. Подготовлен тестовый файл изображения `test_label.jpg` (размер < 10MB).

**Шаги:**
1. Сформировать HTTP POST запрос на эндпоинт `/v1/composition/create/photos`.
2. Установить заголовок `Content-Type: multipart/form-data`.
3. Добавить в форму (form-data):
    - `photos`: [бинарный файл `test_label.jpg`]
    - `scan`: JSON-объект `{"type": "PHOTO", "id": "scan_new_01"}` (как Blob или String, в зависимости от клиента).
4. Отправить запрос.
5. Получить синхронный ответ с ID созданного состава.

**Ожидаемый результат:**
1. Статус ответа: **200 OK**.
2. Ответ содержит `compositionId`.
3. Файл успешно сохранен в хранилище (проверка логов или админки, если доступна).

**Тип теста:** Функциональный API тест
**Связанный метод:** `/composition/create/photos`
