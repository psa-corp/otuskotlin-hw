### Карточка тестового случая

**Название:** Создание состава продукта через API (Ручной ввод)

**Описание:**
Этот кейс проверяет работу метода `POST /composition/create/manual`. Тест подтверждает, что система принимает валидный текст состава и создает новую сущность в базе данных.

**Предусловия:**
1. API доступно (сервер запущен).
2. База данных подключена.

**Шаги:**
1. Сформировать HTTP POST запрос на эндпоинт `/v1/composition/create/manual`.
2. В тело запроса (JSON) добавить обязательные поля:
   - `requestType`: "compositionCreateByManual"
   - `scan`: объект с полями `text` ("молоко, сахар, консервант E202") и `type` ("MANUAL").
3. Отправить запрос.
4. Проверить HTTP статус-код ответа.
5. Проверить тело ответа на наличие поля `compositionId`.

**Ожидаемый результат:**
1. Статус ответа: **200 OK**.
2. В теле ответа JSON содержится непустой `compositionId` (UUID).
3. В базе данных появилась запись с переданным текстом.

**Тип теста:** Интеграционный API тест
**Связанный метод:** `/composition/create/manual`
